# Invifest-style Wedding Invitation

A responsive Next.js + Tailwind CSS digital wedding invitation inspired by the public Invifest demo.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Framework preset: Next.js.
4. Build command: `npm run build`.
5. Deploy.

## Customize

Edit the `wedding` object at the top of `components/WeddingInvitation.tsx`.

Replace the six gallery placeholders with your own images, and update the venue/maps URL.

## Notes

The RSVP demo currently shows a browser confirmation. For real RSVP storage, connect the form to a database, Formspree, Supabase, Firebase, or another backend.
